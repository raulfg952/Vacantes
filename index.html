Dashboard de ofertas de empleo

Ofertas armonizadas desde más de 20 portales de empleo españoles

Acerca de este proyecto
Los datos vienen de un pipeline de scraping + armonización en Python que unifica el formato de cada portal (fechas, tipo de contrato, jornada, salario, ubicación, experiencia exigida...) en un esquema común, para poder analizarlos todos juntos. Algunas variables necesitan bastante trabajo de limpieza porque cada portal las expresa de forma distinta:
  • Ubicación: se resuelve a municipio, provincia y comunidad autónoma a partir del nomenclátor del INE, con más de 8.000 municipios reconocidos.
  • Salario: se normaliza a un importe anual bruto en euros a partir de rangos, distintos periodos (hora/mes/año) y separadores de miles ambiguos.
  • Experiencia exigida: se agrupa en 4 categorías (No se requiere / Más de 6 meses / Más de 2 años / Más de 5 años) a partir de texto libre muy variado entre portales.
  • Tipo de contrato: se reduce a 6 categorías (Indefinido, Temporal, Fijo discontinuo, Autónomo, Prácticas/Formación, Otro) mediante un diccionario editable.
  • Tipo de jornada: se clasifica en Completa / Parcial mediante un diccionario editable, con apoyo en las horas semanales cuando el texto solo trae horarios.
  • Estudios requeridos: se mapea a los niveles educativos de la CNED-2014 (INE), de "Sin estudios" a "Doctorado", conservando la titulación mínima cuando la oferta lista varias.
Este dashboard se sirve como una página estática en GitHub Pages: el fichero ofertas.parquet se descarga una sola vez y todas las consultas (filtros, agregados, gráficas) se ejecutan en el propio navegador con DuckDB-WASM.
